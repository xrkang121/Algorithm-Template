用途：
- 每条边恰好经过一次
- 求欧拉路径 / 欧拉回路
- 字符串拼接、单词接龙、边重排
- 图中“把所有边都走一遍”的构造题

核心算法：
    Hierholzer

复杂度：
    O(V + E)


================================================
一、先分清：欧拉路和欧拉回路
================================================

欧拉路：

    每条边恰好经过一次

欧拉回路：

    每条边恰好经过一次
    并且最后回到起点


注意：

    关心的是“每条边”
    不是“每个点”


================================================
二、无向图存在条件
================================================

只看度数 > 0 的点，并要求这些点属于同一个连通块。


【欧拉回路】

所有点的度数都是偶数：

    odd = 0


【欧拉路但不是回路】

恰好有两个奇度点：

    odd = 2


这两个奇度点：

    一个是起点
    一个是终点


所以无向图：

    odd = 0
        => 欧拉回路

    odd = 2
        => 欧拉路

    其他
        => 不存在


================================================
三、有向图存在条件
================================================

记：

    indeg[x]  = 入度
    outdeg[x] = 出度


【欧拉回路】

对所有点：

    indeg[x] = outdeg[x]


【欧拉路但不是回路】

恰好有：

    一个点：
        outdeg = indeg + 1
        => 起点

    一个点：
        indeg = outdeg + 1
        => 终点

其他点：

    indeg = outdeg


还需要：

    所有有边的点在“忽略方向后”连通


================================================
四、Hierholzer 核心思想
================================================

从起点一直走“还没走过的边”。

如果当前点已经没有可走边：

    把当前点加入答案
    然后回退


所以答案天然是：

    逆序生成


最后：

    reverse(ans.begin(), ans.end());


================================================
五、无向图模板
================================================

无向图一定要给边编号。

因为：

    x -- y

这条边会存两次：

    x -> y
    y -> x

但实际上它们是同一条边。


================================================
六、无向图结构
================================================

struct Edge
{
    int to;
    int id;
};

vector<vector<Edge>> mymap;

vector<int> vis;
vector<int> cur;
vector<int> path;


含义：

    vis[id]
        这条无向边是否已经走过

    cur[x]
        当前处理到 mymap[x] 的第几条边

    path
        最终欧拉路径上的点序列


================================================
七、无向图核心 DFS
================================================

void dfs(int x)
{
    while (cur[x] < mymap[x].size())
    {
        Edge e = mymap[x][cur[x]];
        cur[x]++;

        if (vis[e.id])
        {
            continue;
        }

        vis[e.id] = 1;

        dfs(e.to);
    }

    path.push_back(x);
}


最后：

    reverse(path.begin(), path.end());


================================================
八、无向图完整可运行模板
================================================

#include <bits/stdc++.h>
using namespace std;

#define int long long

struct Edge
{
    int to;
    int id;
};

vector<vector<Edge>> mymap;

vector<int> degree;
vector<int> vis;
vector<int> cur;

vector<int> path;

void dfs(int x)
{
    while (cur[x] < mymap[x].size())
    {
        Edge e = mymap[x][cur[x]];
        cur[x]++;

        if (vis[e.id])
        {
            continue;
        }

        vis[e.id] = 1;

        dfs(e.to);
    }

    path.push_back(x);
}

signed main()
{
    ios::sync_with_stdio(0);
    cin.tie(0), cout.tie(0);

    int n, m;
    cin >> n >> m;

    mymap.resize(n + 1);

    degree.resize(n + 1);

    vis.resize(m + 1);
    cur.resize(n + 1);

    for (int i = 1; i <= m; i++)
    {
        int x, y;
        cin >> x >> y;

        mymap[x].push_back({y, i});
        mymap[y].push_back({x, i});

        degree[x]++;
        degree[y]++;
    }

    int start = 0;
    int odd = 0;

    for (int i = 1; i <= n; i++)
    {
        if (degree[i] % 2 == 1)
        {
            odd++;
            start = i;
        }
    }

    if (odd != 0 && odd != 2)
    {
        cout << "NO\n";
        return 0;
    }

    if (start == 0)
    {
        for (int i = 1; i <= n; i++)
        {
            if (degree[i] > 0)
            {
                start = i;
                break;
            }
        }
    }

    // 没有边
    if (m == 0)
    {
        cout << "YES\n";
        return 0;
    }

    dfs(start);

    // 如果没有经过所有边，说明图不连通
    if (path.size() != m + 1)
    {
        cout << "NO\n";
        return 0;
    }

    reverse(path.begin(), path.end());

    cout << "YES\n";

    for (int i = 0; i < path.size(); i++)
    {
        cout << path[i] << " \n"[i + 1 == path.size()];
    }

    return 0;
}


================================================
九、无向图起点怎么选
================================================

如果有两个奇度点：

    从任意一个奇度点出发


如果所有点度数都是偶数：

    从任意一个度数 > 0 的点出发


如果题目指定起点：

    还要检查指定点是否满足起点条件


================================================
十、有向图模板
================================================

有向边只存一次。

所以不需要：

    vis[id]

只要：

    cur[x]

记录走到哪条边即可。


================================================
十一、有向图核心 DFS
================================================

vector<vector<int>> mymap;

vector<int> cur;
vector<int> path;

void dfs(int x)
{
    while (cur[x] < mymap[x].size())
    {
        int nxt = mymap[x][cur[x]];
        cur[x]++;

        dfs(nxt);
    }

    path.push_back(x);
}


================================================
十二、有向图完整可运行模板
================================================

#include <bits/stdc++.h>
using namespace std;

#define int long long

vector<vector<int>> mymap;

vector<int> indegree;
vector<int> outdegree;

vector<int> cur;
vector<int> path;

void dfs(int x)
{
    while (cur[x] < mymap[x].size())
    {
        int nxt = mymap[x][cur[x]];
        cur[x]++;

        dfs(nxt);
    }

    path.push_back(x);
}

signed main()
{
    ios::sync_with_stdio(0);
    cin.tie(0), cout.tie(0);

    int n, m;
    cin >> n >> m;

    mymap.resize(n + 1);

    indegree.resize(n + 1);
    outdegree.resize(n + 1);

    cur.resize(n + 1);

    for (int i = 1; i <= m; i++)
    {
        int x, y;
        cin >> x >> y;

        mymap[x].push_back(y);

        outdegree[x]++;
        indegree[y]++;
    }

    int start = 0;

    int start_cnt = 0;
    int end_cnt = 0;

    bool flag = true;

    for (int i = 1; i <= n; i++)
    {
        if (outdegree[i] == indegree[i] + 1)
        {
            start = i;
            start_cnt++;
        }
        else if (indegree[i] == outdegree[i] + 1)
        {
            end_cnt++;
        }
        else if (indegree[i] != outdegree[i])
        {
            flag = false;
        }
    }

    if (!flag)
    {
        cout << "NO\n";
        return 0;
    }

    if (!((start_cnt == 0 && end_cnt == 0) ||
          (start_cnt == 1 && end_cnt == 1)))
    {
        cout << "NO\n";
        return 0;
    }

    if (start == 0)
    {
        for (int i = 1; i <= n; i++)
        {
            if (outdegree[i] > 0)
            {
                start = i;
                break;
            }
        }
    }

    if (m == 0)
    {
        cout << "YES\n";
        return 0;
    }

    dfs(start);

    if (path.size() != m + 1)
    {
        cout << "NO\n";
        return 0;
    }

    reverse(path.begin(), path.end());

    cout << "YES\n";

    for (int i = 0; i < path.size(); i++)
    {
        cout << path[i] << " \n"[i + 1 == path.size()];
    }

    return 0;
}


================================================
十三、为什么 path.size() == m+1 很重要
================================================

如果一共：

    m 条边


一个完整欧拉路经过所有边后：

    一定有 m+1 个点


所以：

    path.size() == m+1

可以顺便检查：

    是否真的走完了所有边
    是否有边在另一个不连通块


这是比赛里最省事的连通性检查。


================================================
十四、如果题目要求字典序最小
================================================

先对邻接表排序。


无向图：

for (int i = 1; i <= n; i++)
{
    sort(mymap[i].begin(), mymap[i].end(),
         [](const Edge &a, const Edge &b)
         {
             return a.to < b.to;
         });
}


有向图：

for (int i = 1; i <= n; i++)
{
    sort(mymap[i].begin(), mymap[i].end());
}


然后按顺序走即可。


注意：

如果题目要求：

    字典序最大

改成降序。


================================================
十五、如果边很多，递归可能爆栈
================================================

Hierholzer 递归深度可能达到：

    O(E)


如果：

    E 接近 2e5 / 1e6

递归有爆栈风险。


可以改成栈版本。


================================================
十六、有向图栈版本
================================================

vector<int> stk;

stk.push_back(start);

while (!stk.empty())
{
    int x = stk.back();

    if (cur[x] < mymap[x].size())
    {
        int nxt = mymap[x][cur[x]];
        cur[x]++;

        stk.push_back(nxt);
    }
    else
    {
        path.push_back(x);
        stk.pop_back();
    }
}

reverse(path.begin(), path.end());


================================================
十七、无向图栈版本
================================================

vector<int> stk;

stk.push_back(start);

while (!stk.empty())
{
    int x = stk.back();

    while (cur[x] < mymap[x].size() &&
           vis[mymap[x][cur[x]].id])
    {
        cur[x]++;
    }

    if (cur[x] == mymap[x].size())
    {
        path.push_back(x);
        stk.pop_back();
    }
    else
    {
        Edge e = mymap[x][cur[x]];
        cur[x]++;

        if (vis[e.id])
        {
            continue;
        }

        vis[e.id] = 1;

        stk.push_back(e.to);
    }
}

reverse(path.begin(), path.end());


================================================
十八、字符串拼接题怎么转
================================================

经典形式：

给很多字符串：

    ab
    bc
    cd
    da


如果要求：

    把每个字符串用一次
    并且前一个结尾 = 后一个开头


可以建图：

    字符串首字符 = 起点
    字符串尾字符 = 终点


每个字符串：

    一条有向边


例如：

    "ab"

就是：

    a -> b


然后问题就变成：

    有向图欧拉路


字符串本身对应的是：

    边

不是点。


================================================
十九、单词接龙 / De Bruijn 类题
================================================

如果一个字符串长度为 k：

    前 k-1 个字符
        作为起点

    后 k-1 个字符
        作为终点


整条字符串：

    作为一条边


于是：

    每个字符串恰好用一次

就变成：

    欧拉路


这是很常见的建模。


================================================
二十、欧拉路 vs 哈密顿路
================================================

千万别混。


欧拉路：

    每条边恰好一次


哈密顿路：

    每个点恰好一次


看到：

    “每条边”
    “每个字符串”
    “每张票”
    “每条关系”

更像欧拉路。


看到：

    “每个点都访问一次”

那不是欧拉路。


================================================
二十一、常见易错点
================================================

1.
无向图：

    一条边存两次

一定要有：

    edge id + vis[id]


2.
答案是逆序生成：

    最后 reverse()


3.
起点不能乱选：

无向图：

    odd = 2
        从奇度点开始

有向图：

    out = in + 1
        从这个点开始


4.
最后检查：

    path.size() == m + 1


5.
有重边完全没问题：

    无向图靠 id 区分


6.
自环也可以处理。


================================================
二十二、什么时候想到欧拉路
================================================

看到题目：

    每条边恰好一次

或者：

    每个字符串 / 每张票 / 每个操作
    必须恰好使用一次

并且：

    它们之间能首尾相接


优先考虑：

    建图 + 欧拉路


================================================
二十三、赛场选择
================================================

无向图：

    边编号 + vis[id]
    Hierholzer


有向图：

    cur[x]
    Hierholzer


边很多：

    优先栈版本


要求字典序：

    先排序邻接表


================================================
二十四、最短速记
================================================

无向图：

    欧拉回路：
        奇度点 = 0

    欧拉路：
        奇度点 = 2


有向图：

    欧拉回路：
        ∀x, in[x] = out[x]

    欧拉路：
        一个点 out = in + 1
        一个点 in = out + 1
        其他相等


Hierholzer：

    一直走没走过的边

    没边可走：
        path.push_back(x)

最后：

    reverse(path)


完整性检查：

    path.size() == m + 1
