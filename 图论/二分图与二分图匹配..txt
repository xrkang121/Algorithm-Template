二分图 + 二分图匹配 赛场速查板子
================================

适用目标：
1. 看到“二分图 / 配对 / 一一对应 / 最多选多少对”能马上套。
2. 记住最常用性质和转化。
3. 无权匹配优先写 DFS 增广路；数据大再上 Hopcroft-Karp。
4. 带权完美匹配再考虑 KM。

--------------------------------------------------
一、二分图是什么
--------------------------------------------------

点集能分成两个集合 L、R，并且所有边都只连接：

    L -> R

同一个集合内部没有边。

最常见形式：

    左边：人
    右边：任务
    边：这个人可以做这个任务

匹配：
    选一些边，使得任何两个被选中的边都没有公共端点。

最大匹配：
    能选出的边数最多。

完美匹配：
    所有点都被匹配。
    如果左右各 n 个点，就是最大匹配 = n。


--------------------------------------------------
二、二分图判定：二染色
--------------------------------------------------

重要性质：

    一个无向图是二分图
    <=>
    图中不存在奇环
    <=>
    可以进行二染色

比赛中如果题目没直接告诉你是二分图，可以染色判断。

代码：

vector<vector<int>> mymap;
vector<int> color;

bool check(int s)
{
    queue<int> q;

    color[s] = 1;
    q.push(s);

    while (!q.empty())
    {
        int x = q.front();
        q.pop();

        for (int i = 0; i < mymap[x].size(); i++)
        {
            int nxt = mymap[x][i];

            if (color[nxt] == 0)
            {
                color[nxt] = 3 - color[x];
                q.push(nxt);
            }
            else if (color[nxt] == color[x])
            {
                return false;
            }
        }
    }

    return true;
}

整体：

color.resize(n + 1);

bool flag = true;

for (int i = 1; i <= n; i++)
{
    if (color[i] == 0)
    {
        if (!check(i))
        {
            flag = false;
            break;
        }
    }
}


--------------------------------------------------
三、无权二分图最大匹配：DFS 增广路
--------------------------------------------------

这是最常用的轻量板子。

左部点：

    1 ~ n

右部点：

    1 ~ m

mymap[x]：

    左部点 x 可以连到哪些右部点

match[y]：

    右部点 y 当前匹配的左部点

vis[y]：

    当前这一轮 DFS 是否已经访问过右部点 y


【核心代码】

vector<vector<int>> mymap;

vector<int> match;
vector<int> vis;

bool dfs(int x)
{
    for (int i = 0; i < mymap[x].size(); i++)
    {
        int y = mymap[x][i];

        if (vis[y])
        {
            continue;
        }

        vis[y] = 1;

        if (match[y] == 0 || dfs(match[y]))
        {
            match[y] = x;

            return true;
        }
    }

    return false;
}


【完整调用】

int ans = 0;

for (int i = 1; i <= n; i++)
{
    fill(vis.begin(), vis.end(), 0);

    if (dfs(i))
    {
        ans++;
    }
}

cout << ans << '\n';

【记忆方法】

if (match[y] == 0 || dfs(match[y]))

理解成：

    y 没有人占：
        x 直接占 y

    y 已经有人占：
        让原来匹配 y 的人尝试去找别的位置

    原来的人能挪走：
        y 就归 x


【复杂度】

    O(VE)

严格说通常写成：

    O(|L| * E)

普通比赛题非常够用。

--------------------------------------------------
五、数据大：Hopcroft-Karp
--------------------------------------------------

用途：

    无权二分图最大匹配

优势：

    DFS 增广路：O(VE)
    Hopcroft-Karp：O(E * sqrt(V))

数据到：

    V, E 接近 1e5 / 2e5

时优先考虑 HK。


【板子】

vector<vector<int>> mymap;

vector<int> match_left;
vector<int> match_right;
vector<int> dis;

int n, m;

bool bfs()
{
    queue<int> q;

    for (int i = 1; i <= n; i++)
    {
        if (match_left[i] == 0)
        {
            dis[i] = 0;
            q.push(i);
        }
        else
        {
            dis[i] = -1;
        }
    }

    bool flag = false;

    while (!q.empty())
    {
        int x = q.front();
        q.pop();

        for (int i = 0; i < mymap[x].size(); i++)
        {
            int y = mymap[x][i];
            int nxt = match_right[y];

            if (nxt == 0)
            {
                flag = true;
            }
            else if (dis[nxt] == -1)
            {
                dis[nxt] = dis[x] + 1;
                q.push(nxt);
            }
        }
    }

    return flag;
}

bool dfs_hk(int x)
{
    for (int i = 0; i < mymap[x].size(); i++)
    {
        int y = mymap[x][i];
        int nxt = match_right[y];

        if (nxt == 0 || (dis[nxt] == dis[x] + 1 && dfs_hk(nxt)))
        {
            match_left[x] = y;
            match_right[y] = x;

            return true;
        }
    }

    dis[x] = -1;

    return false;
}

int hopcroft_karp()
{
    match_left.resize(n + 1);
    match_right.resize(m + 1);
    dis.resize(n + 1);

    int ans = 0;

    while (bfs())
    {
        for (int i = 1; i <= n; i++)
        {
            if (match_left[i] == 0 && dfs_hk(i))
            {
                ans++;
            }
        }
    }

    return ans;
}


【什么时候换 HK】

普通题：
    DFS 增广路

点边很大、明显卡 O(VE)：
    Hopcroft-Karp


--------------------------------------------------
六、最大匹配的几个超级重要性质
--------------------------------------------------

设：

    最大匹配数 = M
    总点数 = |V|


1. König 定理

对于二分图：

    最大匹配数
    =
    最小点覆盖大小

即：

    最大匹配 = 最小点覆盖


--------------------------------------------------
2. 最大独立集
--------------------------------------------------

独立集：

    选一些点，使这些点内部没有边。

二分图中：

    最大独立集
    =
    总点数 - 最小点覆盖

再由 König：

    最大独立集大小
    =
    |V| - 最大匹配数

即：

    最大独立集 = |V| - M


--------------------------------------------------
3. 最小边覆盖
--------------------------------------------------

边覆盖：

    选一些边，使每个点至少属于一条被选边。

如果图中没有孤立点：

    最小边覆盖
    =
    总点数 - 最大匹配

即：

    最小边覆盖 = |V| - M

注意：

    有孤立点时不存在覆盖所有点的边覆盖。


--------------------------------------------------
七、最小点覆盖：不仅求大小，还要输出方案
--------------------------------------------------

前提：

    已经求完最大匹配。

方法：

1. 从所有“没有匹配的左部点”开始 BFS / DFS。
2. 左 -> 右：
       只能走“非匹配边”
3. 右 -> 左：
       只能走“匹配边”
4. 最后访问到的点集合记为：
       ZL：左部访问到
       ZR：右部访问到

则：

    最小点覆盖 =
    (左部未访问点)
    +
    (右部已访问点)


如果已经有：

    match_left[x]
    match_right[y]

代码：

vector<int> vis_left(n + 1);
vector<int> vis_right(m + 1);

queue<int> q;

for (int i = 1; i <= n; i++)
{
    if (match_left[i] == 0)
    {
        vis_left[i] = 1;
        q.push(i);
    }
}

while (!q.empty())
{
    int x = q.front();
    q.pop();

    for (int i = 0; i < mymap[x].size(); i++)
    {
        int y = mymap[x][i];

        // 左 -> 右只走非匹配边
        if (match_left[x] == y)
        {
            continue;
        }

        if (vis_right[y])
        {
            continue;
        }

        vis_right[y] = 1;

        // 右 -> 左只走匹配边
        if (match_right[y] != 0)
        {
            int nxt = match_right[y];

            if (!vis_left[nxt])
            {
                vis_left[nxt] = 1;
                q.push(nxt);
            }
        }
    }
}


最后最小点覆盖：

左边：
    vis_left[x] == 0

右边：
    vis_right[y] == 1


--------------------------------------------------
八、最大独立集输出方案
--------------------------------------------------

最大独立集就是最小点覆盖的补集。

上面的搜索做完以后：

最大独立集：

左边：
    vis_left[x] == 1

右边：
    vis_right[y] == 0


--------------------------------------------------
九、DAG 最小路径覆盖
--------------------------------------------------

这是非常常见的转化。

题目：

    给一个 DAG
    用尽量少的若干条路径
    覆盖所有点
    每个点只能出现一次

构造二分图：

原图每个点 i 拆成：

    左 i
    右 i

对于原图一条有向边：

    u -> v

在二分图连：

    左 u -> 右 v

求最大匹配 M。

答案：

    DAG 最小路径覆盖
    =
    n - M


【牢记】

DAG 最小路径覆盖：

    n - 最大匹配


--------------------------------------------------
十、DAG 路径覆盖怎么还原路径
--------------------------------------------------

求完匹配后：

    match_right[v] = u

表示路径里：

    u -> v

可以构造：

vector<int> nxt(n + 1);
vector<int> pre(n + 1);

for (int v = 1; v <= n; v++)
{
    if (match_right[v])
    {
        int u = match_right[v];

        nxt[u] = v;
        pre[v] = u;
    }
}

所有：

    pre[i] == 0

的点就是每条路径的起点。

然后一路：

    i -> nxt[i] -> nxt[nxt[i]] ...


--------------------------------------------------
十一、Hall 定理：判断是否一定存在完美匹配
--------------------------------------------------

对于二分图 G=(L,R)。

存在一个匹配，使得左部所有点都被匹配，当且仅当：

对于任意：

    S ⊆ L

都有：

    |N(S)| >= |S|

其中：

    N(S)

表示 S 中所有点能够连到的右部点集合。


比赛中通常不会真的枚举所有 S。

主要用途：

1. 证明一定存在匹配
2. 证明一定存在完美匹配
3. 构造题 / 数学题


如果：

    |L| = |R| = n

并且 Hall 条件成立，则存在完美匹配。


--------------------------------------------------
十二、带权二分图匹配：KM
--------------------------------------------------

如果边不是“能不能匹配”，而是有权值：

    w[i][j]

并且题目要求：

    一一匹配
    最大化总权值

就是：

    二分图最大权完美匹配

常用：

    KM / Kuhn-Munkres

复杂度：

    O(n^3)


典型：

    n 个人
    n 个任务
    每个人做每个任务收益 w[i][j]
    每人一个任务
    求总收益最大


--------------------------------------------------
十三、KM 最大权完美匹配板子
--------------------------------------------------

适用于：

    左右各 n 个点
    完美匹配
    求最大权值

数组：

    w[x][y]：权值
    lx[x]：左部顶标
    ly[y]：右部顶标
    match[y]：右部 y 匹配的左部点
    slack[y]：当前离成为可行边还差多少


const int INF = 1e18;

int n;

vector<vector<int>> w;

vector<int> lx;
vector<int> ly;
vector<int> match;
vector<int> slack;

vector<int> vis_left;
vector<int> vis_right;

bool dfs_km(int x)
{
    vis_left[x] = 1;

    for (int y = 1; y <= n; y++)
    {
        if (vis_right[y])
        {
            continue;
        }

        int d = lx[x] + ly[y] - w[x][y];

        if (d == 0)
        {
            vis_right[y] = 1;

            if (match[y] == 0 || dfs_km(match[y]))
            {
                match[y] = x;

                return true;
            }
        }
        else
        {
            slack[y] = min(slack[y], d);
        }
    }

    return false;
}

int km()
{
    lx.resize(n + 1);
    ly.resize(n + 1);
    match.resize(n + 1);
    slack.resize(n + 1);

    vis_left.resize(n + 1);
    vis_right.resize(n + 1);

    for (int x = 1; x <= n; x++)
    {
        lx[x] = w[x][1];

        for (int y = 2; y <= n; y++)
        {
            lx[x] = max(lx[x], w[x][y]);
        }
    }

    for (int x = 1; x <= n; x++)
    {
        fill(slack.begin(), slack.end(), INF);

        while (true)
        {
            fill(vis_left.begin(), vis_left.end(), 0);
            fill(vis_right.begin(), vis_right.end(), 0);

            if (dfs_km(x))
            {
                break;
            }

            int d = INF;

            for (int y = 1; y <= n; y++)
            {
                if (!vis_right[y])
                {
                    d = min(d, slack[y]);
                }
            }

            for (int i = 1; i <= n; i++)
            {
                if (vis_left[i])
                {
                    lx[i] -= d;
                }

                if (vis_right[i])
                {
                    ly[i] += d;
                }
                else
                {
                    slack[i] -= d;
                }
            }
        }
    }

    int ans = 0;

    for (int y = 1; y <= n; y++)
    {
        ans += w[match[y]][y];
    }

    return ans;
}


【使用】

w.resize(n + 1);

for (int i = 0; i <= n; i++)
{
    w[i].resize(n + 1);
}

读入：

for (int i = 1; i <= n; i++)
{

    {

    }
}

--------------------------------------------------
十四、KM 怎么改成最小权
--------------------------------------------------

最简单：

读入时：

    w[i][j] = -cost[i][j];

跑最大权 KM。

最后：

    min_cost = -km();


--------------------------------------------------
十五、左右点数不相等怎么办
--------------------------------------------------

如果是带权“完全指派”问题：

    左 n
    右 m

可以补虚点，使：

    N = max(n, m)

变成：

    N x N

虚点边权设 0。

但是：

    如果题目要求“必须匹配真实点”
    或者边不存在

要按照题意处理，不能无脑补 0。


--------------------------------------------------
十六、二分图匹配和网络流
--------------------------------------------------

普通最大匹配也可以建最大流：

    S -> 左部点 -> 右部点 -> T

每条边容量都是：

    1

于是：

    最大流 = 最大匹配


所以：

简单无权二分图：
    DFS 增广路 / HK

限制复杂：
    最大流

带费用：
    最小费用最大流

例如：

    每个左点最多匹配 k 个
    每个右点有容量
    匹配还有费用
    有多个限制

这种往流上想。


--------------------------------------------------
十七、看到题目时怎么判断
--------------------------------------------------

【关键词 1】

    两类对象
    一对一
    最多配多少对

=> 二分图最大匹配


【关键词 2】

    两类对象
    一对一
    每种配对有收益 / 代价
    要最大 / 最小总权值

=> KM / 费用流


【关键词 3】

    最少选多少个点
    让每条边至少有一个端点被选

=> 最小点覆盖
=> 二分图中 = 最大匹配


【关键词 4】

    最多选多少个点
    任意两个选中的点之间没有边

=> 最大独立集
=> 二分图中 = 总点数 - 最大匹配


【关键词 5】

    DAG
    最少几条路径覆盖所有点

=> 拆点建二分图
=> n - 最大匹配


【关键词 6】

    每个点至少属于一条选中的边
    最少选多少条边

=> 最小边覆盖
=> 无孤立点时 = 总点数 - 最大匹配


--------------------------------------------------
十八、网格题怎么转二分图
--------------------------------------------------

网格四联通时很常见。

按照：

    (x + y) % 2

染色。

例如：

    偶数 -> 左部
    奇数 -> 右部

因为四联通每走一步：

    x + y

奇偶性一定变化。

所以网格天然是二分图。

坐标不要直接用 map<pair<int,int>, ...>。

建议编号：

    id = (x - 1) * m + y

四方向：

int way[4][2] =
{
    {0, 1},
    {0, -1},
    {1, 0},
    {-1, 0}
};

如果当前点属于左部：

    mymap[id1].push_back(id2);

然后直接跑匹配。


--------------------------------------------------
十九、最常见易错点
--------------------------------------------------

1. vis 必须每次从一个新的左部点开始 DFS 时清空：

    fill(vis.begin(), vis.end(), 0);


2. DFS 增广路中：

    match[y]

记录的是：

    右部 y 对应的左部点。


3. 建边只需要：

    左 -> 右

不需要再建：

    右 -> 左


4. DAG 路径覆盖一定要：

    每个原点拆成左点和右点

不是直接在原图上匹配。


5. 最大独立集公式：

    |V| - 最大匹配

只是在二分图中使用 König 定理得到的。


6. 最小边覆盖：

    |V| - 最大匹配

要求没有孤立点。


7. KM 是“带权完美匹配”，
   不要和普通 DFS 增广路混在一起。


--------------------------------------------------
二十、赛场优先级
--------------------------------------------------

第一优先：

    DFS 增广路
    必须会现场写

第二优先：

    二分图性质和转化
    最大匹配
    最小点覆盖
    最大独立集
    最小边覆盖
    DAG 最小路径覆盖

第三优先：

    Hopcroft-Karp
    数据大时换

第四优先：

    KM
    带权完美匹配


--------------------------------------------------
二十一、最短速记
--------------------------------------------------

二分图：

    无奇环 <=> 二染色


普通最大匹配：

    DFS 增广路


大规模最大匹配：

    Hopcroft-Karp


König：

    最大匹配 = 最小点覆盖


最大独立集：

    |V| - 最大匹配


最小边覆盖：

    |V| - 最大匹配
    （无孤立点）


DAG 最小路径覆盖：

    n - 最大匹配


完美匹配：

    最大匹配 = n


Hall：

    任意 S⊆L：
    |N(S)| >= |S|


最大权完美匹配：

    KM


复杂限制：

    网络流 / 费用流
