计算几何：叉积

====================
1. 基础代码
====================

struct Point
{
    int x, y;
};

int cross(Point a, Point b)
{
    return a.x * b.y - a.y * b.x;
}

int cross(Point a, Point b, Point c)
{
    return (b.x - a.x) * (c.y - a.y)
         - (b.y - a.y) * (c.x - a.x);
}


用途：

cross(a, b)
= a × b

cross(A, B, C)
= (B - A) × (C - A)


====================
2. 判断方向
====================

int res = cross(a, b);

res > 0
a 转向 b 为逆时针

res < 0
a 转向 b 为顺时针

res == 0
a、b 平行


三个点：

int res = cross(A, B, C);

res > 0
A -> B -> C 左转

res < 0
A -> B -> C 右转

res == 0
A、B、C 共线


====================
3. 判断点在线哪一侧
====================

int res = cross(A, B, P);

res > 0
P 在有向直线 A -> B 左侧

res < 0
P 在有向直线 A -> B 右侧

res == 0
P 在直线上


用途：

点与直线位置关系
凸包
半平面判断


====================
4. 判断三点共线
====================

if (cross(A, B, C) == 0)
{
    // 共线
}


用途：

判断点在线上
线段相交
几何分类


====================
5. 判断两点是否在直线异侧
====================

int c1 = cross(A, B, C);
int c2 = cross(A, B, D);

if (c1 * c2 < 0)
{
    // C、D 严格在直线 AB 两侧
}


如果允许点在线上：

if (c1 * c2 <= 0)
{
}


用途：

线段相交
直线分割
半平面问题


====================
6. 三角形面积
====================

int S2 = abs(cross(A, B, C));

S = S2 / 2


其中：

S2 = 三角形面积的 2 倍


用途：

三角形面积
避免浮点数
面积比较


====================
7. 多边形面积
====================

int area = 0;

for (int i = 0; i < n; i++)
{
    int j = (i + 1) % n;
    area += cross(p[i], p[j]);
}

int S2 = abs(area);


结论：

area > 0
顶点逆时针

area < 0
顶点顺时针

abs(area) / 2
多边形面积


用途：

多边形面积
判断多边形方向


====================
8. 线段严格相交
====================

int c1 = cross(A, B, C);
int c2 = cross(A, B, D);
int c3 = cross(C, D, A);
int c4 = cross(C, D, B);

if (c1 * c2 < 0 && c3 * c4 < 0)
{
    // 严格相交
}


用途：

判断两线段是否内部相交


注意：

端点相交、共线重叠需要额外判断点在线段上。


====================
9. 凸包
====================

while (st.size() >= 2 &&
       cross(st[st.size() - 2], st.back(), p) <= 0)
{
    st.pop_back();
}


用途：

判断当前转向是否合法
Andrew / Graham 凸包核心


<= 0：

删除共线中间点


< 0：

保留边界共线点


====================
10. 点积配合：点在线段上
====================

int dot(Point a, Point b, Point c)
{
    return (b.x - a.x) * (c.x - a.x)
         + (b.y - a.y) * (c.y - a.y);
}


判断 P 在线段 AB 上：

cross(A, B, P) == 0
并且

(P - A) · (P - B) <= 0


常用写法：

if (cross(A, B, P) == 0 &&
    (P.x - A.x) * (P.x - B.x)
  + (P.y - A.y) * (P.y - B.y) <= 0)
{
}


用途：

线段相交
端点判断
共线重叠


====================
11. 叉积性质
====================

a × b = -(b × a)

a × a = 0

a × (b + c)
= a × b + a × c

(a + b) × c
= a × c + b × c

(k * a) × b
= k * (a × b)


用途：

推公式
化简几何表达式


====================
12. 核心结论
====================

cross(A, B, C)
= (B - A) × (C - A)


> 0
左转 / 逆时针 / 左侧

< 0
右转 / 顺时针 / 右侧

= 0
共线


abs(cross(A, B, C))

= 三角形面积的 2 倍


常见场景：

方向判断
共线
点在线哪侧
线段相交
三角形面积
多边形面积
凸包
点在凸多边形内
旋转卡壳
半平面交
