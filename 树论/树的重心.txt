树的重心板子

功能：

假设你已经建立好一棵 n 个结点的树，调用 getCenter(n)，返回这棵树的一个或两个重心。

结点编号默认是 1 到 n。


==================================================
一、需要提前准备什么
==================================================

你需要提前建立好邻接表：

const int MAXN = 2e5 + 5;

vector<vector<int>> tree(MAXN, vector<int>());

例如读入一条边：

int u, v;
cin >> u >> v;

tree[u].push_back(v);
tree[v].push_back(u);


==================================================
二、直接复制的板子
==================================================

vector<int> siz;
vector<int> center;

void dfsCenter(int x, int fa, int n)
{
    siz[x] = 1;

    // 删除 x 后，最大的连通块大小
    int mymax = 0;

    for (int i = 0; i < tree[x].size(); i++)
    {
        int now = tree[x][i];

        if (now == fa)
        {
            continue;
        }

        dfsCenter(now, x, n);

        siz[x] += siz[now];

        // 删除 x 后，now 的子树成为一个连通块
        mymax = max(mymax, siz[now]);
    }

    // 删除 x 后，父亲方向的结点组成一个连通块
    mymax = max(mymax, n - siz[x]);

    // 所有连通块都不超过整棵树的一半，x 就是重心
    if (mymax * 2 <= n)
    {
        center.push_back(x);
    }
}

vector<int> getCenter(int n)
{
    siz.assign(n + 1, 0);
    center.clear();

    // 树上任意选择一个点作为根即可
    dfsCenter(1, 0, n);

    return center;
}


==================================================
三、怎么用
==================================================

第一步：正常建立树。

for (int i = 1; i < n; i++)
{
    int u, v;
    cin >> u >> v;

    tree[u].push_back(v);
    tree[v].push_back(u);
}

第二步：调用 getCenter。

vector<int> res = getCenter(n);

第三步：使用返回的重心。

if (res.size() == 1)
{
    // 只有一个重心
    int root = res[0];
}
else
{
    // 有两个重心，它们一定相邻
    int root1 = res[0];
    int root2 = res[1];
}


如果题目需要输出重心：

vector<int> res = getCenter(n);

cout << res.size() << "\n";

for (int i = 0; i < res.size(); i++)
{
    cout << res[i] << " ";
}

cout << "\n";


==================================================
四、板子返回什么
==================================================

getCenter(n) 返回 vector<int>：

1. res.size() == 1：树只有一个重心，重心是 res[0]。
2. res.size() == 2：树有两个重心，分别是 res[0]、res[1]。

一棵树一定有重心，并且最多只有两个重心。


==================================================
五、核心原理
==================================================

删除点 x 后，产生的连通块包括：

1. 每个儿子对应的子树，大小是 siz[儿子]。
2. 父亲方向的部分，大小是 n-siz[x]。

取这些连通块大小的最大值 mymax。

如果：

mymax * 2 <= n

那么删除 x 后的所有连通块都不超过 n/2，因此 x 是重心。


==================================================
六、需要注意
==================================================

1. 调用 getCenter(n) 前必须已经建立好 tree。
2. 默认结点编号是 1 到 n，DFS 从结点 1 开始。
3. 多组测试数据时，需要在读入前清空 tree[i]。
4. 这是一棵普通无权树，siz 统计结点数量。
5. 递归深度最坏为 O(n)，深链可能爆栈；需要时改成显式栈。
6. 不要随便缩掉二度点，那是部分题目的特殊操作，不属于重心板子。
