博弈论 06 —— 对称策略 / 奇偶性 / 不变量
============================================================
【什么时候用】
1. 图形、棋盘、序列有中心对称、镜像、旋转或成对元素；可尝试“对方怎么动，我就对应怎么动”。
2. 每次操作会让某个可计算的整数恰好 +1 或 -1，终态的该数固定；总步数奇偶固定。
3. 双方轮流选择对象，操作可分组、配对、反制；难以直接做 SG，但存在保持不变量的策略。

【怎么用：对称策略】
第 1 步：找到一个配对映射 f，要求 f(f(x))=x（对合），并优先检查有没有固定点 f(x)=x。
第 2 步：证明对手操作 x 后，自己执行 f(x) 仍然合法。
第 3 步：证明回合结束后，局面仍保持对称，且自己不会提前失去合法回复。
第 4 步：基于先手/后手、终止条件判断谁赢。
只有视觉上对称不够；必须证明“每一步镜像回复都合法”。

【怎么用：奇偶性】
找一个不变量或势函数 P。若每一步 P 恰好下降 1，终态 P=0，那么不管如何选择，操作总次数固定等于初始 P。
正常玩法下，P 奇数先手赢，P 偶数后手赢。
如果每步可能下降 1 或 2，通常不能只看 P 的奇偶！需要分析具体可达性。

【板子 A：相邻逆序交换博弈，逆序数奇偶，独立可运行 C++17】
规则：输入一个数组，每次必须找到相邻逆序对 a[i]>a[i+1] 并交换，不能操作者输。
每一步逆序数恰好 -1，终态非递减数组的逆序数为 0；因此逆序数奇偶决定胜负。
代码用树状数组 O(n log n) 计算逆序数，支持重复元素。
```cpp
#include <bits/stdc++.h>
using namespace std;
#define int long long

signed main()
{
    ios::sync_with_stdio(0);
    cin.tie(0), cout.tie(0);

    int n;
    cin >> n;
    vector<int> a(n + 1), b;
    for (int i = 1; i <= n; i++)
    {
        cin >> a[i];
        b.push_back(a[i]);
    }

    sort(b.begin(), b.end());
    b.erase(unique(b.begin(), b.end()), b.end());
    int m = b.size();

    vector<int> bit(m + 1, 0);
    auto add = [&](int x)
    {
        for (; x <= m; x += x & -x) bit[x]++;
    };
    auto query = [&](int x)
    {
        int res = 0;
        for (; x > 0; x -= x & -x) res += bit[x];
        return res;
    };

    int inv = 0;
    for (int i = 1; i <= n; i++)
    {
        int x = lower_bound(b.begin(), b.end(), a[i]) - b.begin() + 1;
        inv += i - 1 - query(x);
        add(x);
    }

    cout << (inv & 1 ? "First" : "Second") << "\n";
    return 0;
}
```

【板子 B：镜像配对的通用“分析骨架”（不是所有游戏都能直接套的程序）】
例：有 2k 个对称位置，任一步选一个尚未选过的位置；对方之后可以选其镜像，且两个位置互不相同。
镜像编号：f(i)=n+1-i（n 为偶数）。后手第一轮无需主动选择，之后每次对方选 i，就选 f(i)。
结果：后手每轮都可以成对回复，最终后手做最后一次操作而赢。
在更复杂的题里必须检查：镜像位置是否被占、会不会被规则禁止、是否存在中心点/障碍物。

【板子 C：小范围胜负打表校验器，独立可运行 C++17】
输入 maxn k，k 个正整数 d[i]；一堆 x 石子，每步取允许的数量。输出 0..maxn 的胜负序列。
用途：发现奇偶/周期候选规律，用来验证猜想，不能代替数学证明。
```cpp
#include <bits/stdc++.h>
using namespace std;
#define int long long

signed main()
{
    ios::sync_with_stdio(0);
    cin.tie(0), cout.tie(0);

    int n, k;
    cin >> n >> k;
    vector<int> op(k);
    for (int &x : op) cin >> x;

    vector<int> win(n + 1, 0);
    for (int x = 1; x <= n; x++)
    {
        for (int d : op)
        {
            if (d <= x && !win[x - d])
            {
                win[x] = 1;
                break;
            }
        }
    }

    for (int i = 0; i <= n; i++) cout << win[i] << " \n"[i == n];
    return 0;
}
```

【易错】
1. 对称策略不等于“必然后手赢”；要考虑谁能建立对称局面、先后手是谁、中心固定点是否可处理。
2. 具有奇偶性 != 操作次数的奇偶固定；若有操作一次改动 2 或能原地循环，就需重新分析。
3. 不变量只是限制可达状态；要推出必胜，还需证明对应策略存在。
