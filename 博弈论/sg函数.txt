博弈论 01 —— SG 函数（核心：什么时候用 + 怎么转移 + mex）
============================================================
【什么时候用】
1. 两人轮流操作，双方可用操作规则相同（公平组合游戏），不存在随机性，谁不能操作谁输（正常玩法）。
2. 游戏保证有限步结束；状态转移构成 DAG，或者每次操作让某个量严格下降。
3. 需要处理多个独立子游戏：每一步只选择一个子游戏操作，此时整体 SG = 各子游戏 SG 按位异或。
4. 只问单个游戏输赢时，直接用必胜/必败 DP 往往更简单；要合并独立游戏时 SG 尤其有用。
【不能硬套】有环且允许无限游戏、双方操作不同、最后操作者输的反常玩法，都不能直接按以下定理套用。

【怎么用】
步骤 1：定义状态 x，明确“当前轮到谁操作”以外还有没有必须记录的信息。
步骤 2：列出从 x 一步能到的全部状态 y，注意是“一步”，不是任意多步。
步骤 3：sg[x] = mex({ sg[y] | x -> y })；无后继时 sg[x] = 0。
步骤 4：单个状态 sg[x] = 0 为必败，非零为必胜；多个独立游戏异或后 = 0 为必败。
步骤 5：若操作把一个游戏分裂成若干独立游戏，该操作的后继值是它们 SG 的异或，再参与 mex。

【mex 的关键技巧】
设当前去重前共有 d 个合法后继，必有 mex <= d。
所以标记数组只需要 d+1 个位置；后继 SG > d 的值可直接忽略！
注意：仅按后继数量开数组，不能直接 vis[sg[y]]，必须判断 sg[y] <= d 才标记。

【mex 写法 A：普通标记，O(d)，最推荐】
假设 next_sg 保存全部后继 SG 值：
int mex(vector<int> &next_sg)
{
    int d = next_sg.size();
    vector<int> vis(d + 1, 0);
    for (int v : next_sg)
    {
        if (0 <= v && v <= d) vis[v] = 1;
    }
    int res = 0;
    while (vis[res]) res++;
    return res;
}

【mex 写法 B：时间戳，批量计算且 SG 上界可预先分配，O(d)】
当很多状态反复求 mex 时，避免重复清空大数组：
vector<int> mark(MAXN + 1, 0);
int timer = 0;
int mex(vector<int> &next_sg)
{
    ++timer;
    int d = next_sg.size();
    for (int v : next_sg)
    {
        if (0 <= v && v <= d) mark[v] = timer;
    }
    int res = 0;
    while (mark[res] == timer) res++;
    return res;
}
注：MAXN 要 >= 单次最大后继数量；时间戳溢出前重置 mark（int64 下通常不用担心）。

【mex 写法 C：排序 + 去重，O(d log d)，不方便开标记时】
int mex(vector<int> a)
{
    sort(a.begin(), a.end());
    int res = 0;
    for (int x : a)
    {
        if (x == res) res++;
    }
    return res;
}

【mex 写法 D：64 位掩码，后继数量 <= 63 时，O(d)】
int mex(vector<int> &a)
{
    unsigned long long mask = 0;
    for (int x : a)
    {
        if (0 <= x && x < 64) mask |= (1ULL << x);
    }
    if (mask == ~0ULL) return 64;
    return __builtin_ctzll(~mask);
}
注：若后继数 <= 63，则 mex <= 63；不会遇到 64 位全 1；一般用数组版就足够。

【板子 A：一般 DAG 上的 SG —— 独立可运行 C++17】
输入：n m s，接着 m 条有向边 u v；保证 DAG，求起点 s 的 SG 和胜负。
需要改：若题目不是“点沿有向边走”，只改 g[u] 的后继定义。
```cpp
#include <bits/stdc++.h>
using namespace std;

#define int long long

int n, m, s;
vector<vector<int>> g;
vector<int> sg;

int get_sg(int u)
{
    if (sg[u] != -1) return sg[u];

    int d = g[u].size();
    vector<int> vis(d + 1, 0);

    for (int v : g[u])
    {
        int x = get_sg(v);
        if (x <= d) vis[x] = 1;
    }

    int res = 0;
    while (vis[res]) res++;
    return sg[u] = res;
}

signed main()
{
    ios::sync_with_stdio(0);
    cin.tie(0), cout.tie(0);

    cin >> n >> m >> s;
    g.resize(n + 1);
    sg.assign(n + 1, -1);

    for (int i = 1; i <= m; i++)
    {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
    }

    int ans = get_sg(s);
    cout << ans << "\n";
    cout << (ans ? "First" : "Second") << "\n";
    return 0;
}
```
复杂度 O(n+m)，递归深度可能为 O(n)，深 DAG 注意栈溢出，必要时换拓扑序倒推。

【板子 B：多堆取石子 SG + 异或 —— 独立可运行 C++17】
输入：n k；k 个正整数表示每次允许取走的数量；n 个堆大小。
需要改：允许的操作 op 和后继状态 x-d；若不是石子模型就改这里。
```cpp
#include <bits/stdc++.h>
using namespace std;

#define int long long

vector<int> op, sg;

int get_sg(int x)
{
    if (sg[x] != -1) return sg[x];
    int d = op.size();
    vector<int> vis(d + 1, 0);

    for (int k : op)
    {
        if (k > x) continue;
        int v = get_sg(x - k);
        if (v <= d) vis[v] = 1;
    }

    int res = 0;
    while (vis[res]) res++;
    return sg[x] = res;
}

signed main()
{
    ios::sync_with_stdio(0);
    cin.tie(0), cout.tie(0);

    int n, k;
    cin >> n >> k;
    op.resize(k);
    for (int &x : op) cin >> x;

    vector<int> a(n + 1);
    int mx = 0;
    for (int i = 1; i <= n; i++)
    {
        cin >> a[i];
        mx = max(mx, a[i]);
    }

    sg.assign(mx + 1, -1);
    sg[0] = 0;

    int ans = 0;
    for (int i = 1; i <= n; i++) ans ^= get_sg(a[i]);
    cout << (ans ? "First" : "Second") << "\n";
    return 0;
}
```
注意 op 必须全为正数；mx 很大时不能直接 O(mx) 开数组，应改稀疏记忆化 / 找规律。
重复的操作允许存在，不影响正确性，但可先排序去重。

【赛场易错】
1. mex 是未出现的最小非负整数，不是最大值加一，不是集合大小。
2. SG 的异或前提是“每一步仅动一个独立组件”；同时改多局或组件相互影响时不能直接异或。
3. sg[u] 从直接后继 sg[v] 计算；若拆成两局后继要先 sg[a] ^ sg[b]。
4. 纯粹胜负 DP 不等于 SG 数值，不要把 win[x] 直接当 SG[x] 去异或。
5. SG 序列打表可猜周期，但比赛里必须有题目范围支持或严格证明，不能无依据假设周期。
