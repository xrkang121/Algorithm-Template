SG 函数（Sprague-Grundy）—— ACM / ICPC 赛场现学现用板子
============================================================

一、解决什么题
------------------------------------------------------------
适用于：两人轮流操作、无法操作的人输、双方最优、游戏一定会结束，
并且每个局面有哪些下一步合法局面可以明确枚举的「无偏博弈」。

常见题型：取石子、多个独立石子堆、在有向无环图上走点、树上游戏。

二、必须知道的结论
------------------------------------------------------------
1. mex(S)：S 中没有出现的最小非负整数。
   mex({})=0；mex({1,2})=0；mex({0,2})=1；mex({0,1,3})=2。

2. SG(x) = mex({ SG(y) | 从 x 可以一步走到 y })。
   没有合法操作时 SG(x)=0。

3. 单个游戏：SG(x)=0 为必败态；SG(x)!=0 为必胜态。

4. 多个【独立】游戏（每次只能选择一个游戏操作）：
   ans = SG(x1) ^ SG(x2) ^ ... ^ SG(xn)
   ans==0：先手必败；ans!=0：先手必胜。
   ^ 是按位异或，不是乘方。

注意：以上按「不能操作的人输」（正常规则）处理。
如果题目规定「不能操作的人赢」，不能直接套结论。

三、通用 SG 板子：把状态连成有向无环图（推荐先记这个）
------------------------------------------------------------
【解决什么】
每个状态是一个点 u；u -> v 表示从 u 一步合法操作可以到 v。
只要图无环，就能用记忆化搜索求出 SG(u)。

【代码：可直接编译运行】

#include <bits/stdc++.h>
using namespace std;

#define int long long

int n, m, q;
vector<vector<int>> g;
vector<int> sg;

// 返回状态 u 的 SG 值
int get_sg(int u)
{
    if (sg[u] != -1)
    {
        return sg[u];
    }

    int d = g[u].size();
    vector<int> vis(d + 1, 0);

    // 枚举从 u 出发，一步能到达的全部状态 v
    for (int v : g[u])
    {
        int x = get_sg(v);
        if (x <= d)
        {
            vis[x] = 1;
        }
    }

    // mex：找最小的没出现过的非负整数
    int res = 0;
    while (vis[res])
    {
        res++;
    }

    return sg[u] = res;
}

signed main()
{
    ios::sync_with_stdio(0);
    cin.tie(0), cout.tie(0);

    // 这个 main 是演示输入格式：n 个状态、m 条合法转移、q 个查询
    cin >> n >> m >> q;

    g.resize(n + 1);
    sg.assign(n + 1, -1);

    for (int i = 1; i <= m; i++)
    {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v); // u 能一步到 v
    }

    while (q--)
    {
        int x;
        cin >> x;
        cout << get_sg(x) << "\n";
    }

    return 0;
}

【怎么用】
1. 先想清楚「一个状态是什么」（一个点、一个数、一个局面）。
2. 对每个状态 u，枚举所有能一步转移到的 v，加入 g[u]。
3. 初始化 sg.assign(状态总数+1, -1)。-1 表示还没计算。
4. 调用 get_sg(u)：返回 u 的 SG 值；没有出边时自动返回 0。
5. 多个独立游戏：ans ^= get_sg(起点状态)。
6. 比赛时题目输入格式通常不同：保留 get_sg 和数组，重写 main 建图即可。

【为什么 vis 要开 d+1】
当前状态只有 d 个后继，mex 最大为 d。
后继的 SG 值若大于 d，不影响 mex，所以可以不标记。
这样不会因为 SG 值很大导致数组越界。

【复杂度】
每个状态最多计算一次，每条转移最多访问一次：O(V+E) 时间。
保存图、SG 和访问标记：O(V+E) 空间（不含递归栈）。

四、取石子常用版：允许取走 op 中的数量（完整示例）
------------------------------------------------------------
【题型】
有 n 堆石子，第 i 堆有 a[i] 个；每次从其中一堆拿走 op 中的某个数量；
不能操作的人输。问先手能否获胜。

【代码：可直接编译运行】

#include <bits/stdc++.h>
using namespace std;

#define int long long

signed main()
{
    ios::sync_with_stdio(0);
    cin.tie(0), cout.tie(0);

    int n, k;
    cin >> n >> k;

    vector<int> op(k);
    for (int i = 0; i < k; i++)
    {
        cin >> op[i]; // 每次允许取走的石子数（必须 > 0）
    }

    vector<int> a(n + 1);
    int mx = 0;

    for (int i = 1; i <= n; i++)
    {
        cin >> a[i];
        mx = max(mx, a[i]);
    }

    vector<int> sg(mx + 1, 0);

    // sg[0]=0；因为只会从较大堆数转移到较小堆数，可以递推
    for (int x = 1; x <= mx; x++)
    {
        vector<int> vis(k + 1, 0);

        for (int d : op)
        {
            if (x >= d)
            {
                int v = sg[x - d];
                if (v <= k)
                {
                    vis[v] = 1;
                }
            }
        }

        int res = 0;
        while (vis[res])
        {
            res++;
        }
        sg[x] = res;
    }

    int ans = 0;
    for (int i = 1; i <= n; i++)
    {
        ans ^= sg[a[i]];
    }

    cout << (ans ? "First\n" : "Second\n");
    return 0;
}

【本题输入（本示例自定义）】
第一行 n k；第二行 k 个允许拿的数量；第三行 n 堆石子数。

例如：
2 2
1 2
3 4

输出：
First

因为 SG(3)=0、SG(4)=1，总异或值是 1，先手必胜。

【赛场要改什么】
1. op：从题意读入 / 生成「当前可以做的操作」。
2. 转移：sg[x - d]；若操作不是拿走 d 个，这里按题改。
3. 终止状态：不能操作时 SG=0。
4. 如果只研究一个局面，就直接判断 sg[x] 是否为 0，不需要异或。
5. 如果有多个独立局面，每次只能改一个局面，才用 ans ^= sg[a[i]]。

【复杂度】O(mx * k) 时间，O(mx + k) 额外空间。

五、手算例子：每次拿 1 或 2 个石子
------------------------------------------------------------
SG(0)=0（不能操作）
SG(1)=mex({SG(0)})       =mex({0})   =1
SG(2)=mex({SG(1),SG(0)}) =mex({1,0}) =2
SG(3)=mex({SG(2),SG(1)}) =mex({2,1}) =0
SG(4)=mex({SG(3),SG(2)}) =mex({0,2}) =1
SG(5)=mex({SG(4),SG(3)}) =mex({1,0}) =2

序列：0,1,2,0,1,2,...  即 SG(x)=x%3（仅此规则成立）。

六、拿到新题先判断什么（赛场速记）
------------------------------------------------------------
① 当前状态是什么？能否用一个整数 / 一个点表示？
② 一步能去哪里？把所有合法后继完整枚举出来。
③ 状态转移会不会成环？通用 DFS 板子要求无环。
④ 无法操作时 SG=0；其他 SG=mex(后继 SG 集合)。
⑤ 只求一个局面的胜负：SG==0 先手败。
⑥ 多个独立游戏、每步只操作其中一个：异或 SG 值再判断。

常见错误：
- 把 mex 误认为最小值：mex 是最小【未出现】非负整数。
- 不判断转移是否合法，比如 x<d 还调用 sg[x-d]。
- 把所有 SG 相加，而不是按位异或。
- 把两个会相互影响的局面当成独立游戏异或。
- 在含环的图上直接用递归 SG 板子。
- 误把「不能操作的人赢」题套用正常玩法的 SG 结论。
- 状态太大，不能开到 mx 时，应寻找规律、周期或压缩状态。

记忆一句话：
SG = 所有一步后继 SG 值的 mex；多个独立游戏的 SG 按位异或。
