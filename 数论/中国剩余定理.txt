用途：
- 合并多个同余方程
- 求一个数 x，同时满足：

      x ≡ a1 (mod m1)
      x ≡ a2 (mod m2)
      ...
      x ≡ an (mod mn)

- 周期同步
- “第几次同时发生”
- 多个模条件合并


================================================
一、先看题目长什么样
================================================

典型形式：

    x ≡ a1 (mod m1)
    x ≡ a2 (mod m2)
    ...
    x ≡ an (mod mn)


含义：

    x % mi = ai


目标通常是：

    求最小非负解 x

或者：

    判断有没有解


================================================
二、CRT 和 exCRT 的区别
================================================

【普通 CRT】

要求：

    m1, m2, ..., mn

两两互质：

    gcd(mi, mj) = 1


这种一定有唯一解：

    x (mod M)

其中：

    M = m1 m2 ... mn


------------------------------------------------

【exCRT】

模数不要求互质。


例如：

    x ≡ 2 (mod 6)
    x ≡ 5 (mod 9)


这时候要先判断：

    是否有解


所以比赛里：

    模数两两互质
        -> CRT

    模数可能不互质
        -> exCRT


如果懒得区分：

    exCRT 可以直接处理普通 CRT

所以实战中：
    优先留 exCRT 板子


================================================
三、普通 CRT 数学公式
================================================

方程：

    x ≡ ai (mod mi)

且所有 mi 两两互质。


令：

    M = ∏ mi

    Mi = M / mi


再求：

    ti ≡ Mi^(-1) (mod mi)


也就是：

    Mi · ti ≡ 1 (mod mi)


那么：

    x
    ≡
    Σ ai Mi ti
    (mod M)


即：

          n
    x ≡   Σ ai Mi ti   (mod M)
         i=1


最后取：

    x = (x % M + M) % M


================================================
四、普通 CRT 为什么成立
================================================

看第 i 项：

    ai Mi ti


因为：

    Mi ti ≡ 1 (mod mi)

所以：

    ai Mi ti ≡ ai (mod mi)


而对 j ≠ i：

    mj | Mi

所以：

    ai Mi ti ≡ 0 (mod mj)


于是把所有项加起来后：

    对每个 mi

都恰好满足：

    x ≡ ai (mod mi)


================================================
五、扩展欧几里得
================================================

CRT / exCRT 都会用到：

    ax + by = gcd(a,b)


板子：

int exgcd(int a, int b, int &x, int &y)
{
    if (b == 0)
    {
        x = 1;
        y = 0;

        return a;
    }

    int x1, y1;

    int d = exgcd(b, a % b, x1, y1);

    x = y1;
    y = x1 - (a / b) * y1;

    return d;
}


如果：

    gcd(a,m)=1

那么：

    ax + my = 1


所以：

    ax ≡ 1 (mod m)

因此：

    x

就是：

    a 在模 m 下的逆元


================================================
六、普通 CRT 代码
================================================

前提：

    所有模数两两互质


int CRT(const vector<int> &a, const vector<int> &m)
{
    int n = a.size();

    int M = 1;

    for (int i = 0; i < n; i++)
    {
        M *= m[i];
    }

    __int128 ans = 0;

    for (int i = 0; i < n; i++)
    {
        int Mi = M / m[i];

        int x, y;

        exgcd(Mi, m[i], x, y);

        x %= m[i];

        if (x < 0)
        {
            x += m[i];
        }

        ans += (__int128)a[i] * Mi * x;
    }

    ans %= M;

    if (ans < 0)
    {
        ans += M;
    }

    return (int)ans;
}


调用：

vector<int> a(n);
vector<int> m(n);

for (int i = 0; i < n; i++)
{
    cin >> m[i] >> a[i];
}

cout << CRT(a, m) << '\n';


================================================
七、exCRT 最核心：只会“合并两个方程”就够了
================================================

现在看两个方程：

    x ≡ a1 (mod m1)

    x ≡ a2 (mod m2)


我们要把它们合成：

    x ≡ A (mod M)


------------------------------------------------
第一步
------------------------------------------------

因为：

    x ≡ a1 (mod m1)

所以一定可以写成：

    x = a1 + m1 k


代入第二个方程：

    a1 + m1 k ≡ a2 (mod m2)


移项：

    m1 k ≡ a2 - a1 (mod m2)


记：

    c = a2 - a1


于是要解：

    m1 k ≡ c (mod m2)


================================================
八、什么时候无解
================================================

对于：

    m1 k ≡ c (mod m2)


令：

    d = gcd(m1,m2)


有解的充要条件：

    d | c


也就是：

    c % d == 0


所以两个同余方程：

    x ≡ a1 (mod m1)
    x ≡ a2 (mod m2)


有解当且仅当：

    (a2-a1) % gcd(m1,m2) == 0


这个条件一定要记。


================================================
九、有解以后怎么求 k
================================================

有：

    m1 k ≡ c (mod m2)


令：

    d = gcd(m1,m2)


两边除 d：

    (m1/d) k
    ≡
    c/d
    (mod m2/d)


此时：

    gcd(m1/d, m2/d) = 1


所以：

    m1/d

在模：

    m2/d

下存在逆元。


设：

    inv ≡ (m1/d)^(-1) (mod m2/d)


那么：

    k
    ≡
    (c/d) · inv
    (mod m2/d)


================================================
十、合并后的新模数
================================================

合并以后：

    x = a1 + m1 k


新模数：

    lcm(m1,m2)

即：

    M = m1/d * m2


然后：

    A = a1 + m1 k


最后标准化：

    A %= M

    若 A < 0：
        A += M


于是两个方程合成：

    x ≡ A (mod M)


然后继续和第三个方程合并即可。


================================================
十一、exCRT 核心合并函数
================================================

bool merge_equation(
    int &a1,
    int &m1,
    int a2,
    int m2
)
{
    // 当前：
    // x ≡ a1 (mod m1)

    // 新加入：
    // x ≡ a2 (mod m2)

    int x, y;

    int d = exgcd(m1, m2, x, y);

    int c = a2 - a1;

    if (c % d != 0)
    {
        return false;
    }

    int mod = m2 / d;

    // x 是 m1/d 在 mod 下的逆元
    __int128 k =
        (__int128)(c / d) * x;

    k %= mod;

    if (k < 0)
    {
        k += mod;
    }

    __int128 new_mod =
        (__int128)m1 / d * m2;

    __int128 new_a =
        (__int128)a1 + (__int128)m1 * k;

    new_a %= new_mod;

    if (new_a < 0)
    {
        new_a += new_mod;
    }

    a1 = (int)new_a;
    m1 = (int)new_mod;

    return true;
}


================================================
十二、完整 exCRT 板子
================================================

#include <bits/stdc++.h>
using namespace std;

#define int long long

int exgcd(int a, int b, int &x, int &y)
{
    if (b == 0)
    {
        x = 1;
        y = 0;

        return a;
    }

    int x1, y1;

    int d = exgcd(b, a % b, x1, y1);

    x = y1;
    y = x1 - (a / b) * y1;

    return d;
}


bool merge_equation(
    int &a1,
    int &m1,
    int a2,
    int m2
)
{
    int x, y;

    int d = exgcd(m1, m2, x, y);

    int c = a2 - a1;

    if (c % d != 0)
    {
        return false;
    }

    int mod = m2 / d;

    __int128 k =
        (__int128)(c / d) * x;

    k %= mod;

    if (k < 0)
    {
        k += mod;
    }

    __int128 new_mod =
        (__int128)m1 / d * m2;

    __int128 new_a =
        (__int128)a1 + (__int128)m1 * k;

    new_a %= new_mod;

    if (new_a < 0)
    {
        new_a += new_mod;
    }

    a1 = (int)new_a;
    m1 = (int)new_mod;

    return true;
}


pair<bool, int> exCRT(
    const vector<int> &a,
    const vector<int> &m
)
{
    int n = a.size();

    int now_a = a[0];
    int now_m = m[0];

    now_a %= now_m;

    if (now_a < 0)
    {
        now_a += now_m;
    }

    for (int i = 1; i < n; i++)
    {
        int nxt_a = a[i] % m[i];

        if (nxt_a < 0)
        {
            nxt_a += m[i];
        }

        if (!merge_equation(
                now_a,
                now_m,
                nxt_a,
                m[i]
            ))
        {
            return {false, -1};
        }
    }

    return {true, now_a};
}


signed main()
{
    ios::sync_with_stdio(0);
    cin.tie(0), cout.tie(0);

    int n;
    cin >> n;

    vector<int> a(n);
    vector<int> m(n);

    for (int i = 0; i < n; i++)
    {
        cin >> m[i] >> a[i];
    }

    auto [flag, ans] = exCRT(a, m);

    if (!flag)
    {
        cout << -1 << '\n';
    }
    else
    {
        cout << ans << '\n';
    }

    return 0;
}

十三、最推荐的输入习惯
================================================

建议每个方程输入：

    mi ai


表示：

    x ≡ ai (mod mi)


例如：

输入：

3
3 2
5 3
7 2


表示：

    x ≡ 2 (mod 3)
    x ≡ 3 (mod 5)
    x ≡ 2 (mod 7)


================================================
十四、手推一个 exCRT
================================================

方程：

    x ≡ 2 (mod 6)

    x ≡ 8 (mod 9)


令：

    x = 2 + 6k


代入：

    2 + 6k ≡ 8 (mod 9)


得到：

    6k ≡ 6 (mod 9)


因为：

    gcd(6,9)=3


且：

    3 | 6


所以有解。


两边除 3：

    2k ≡ 2 (mod 3)


2 在 mod 3 下逆元是 2：

    k ≡ 1 (mod 3)


取：

    k=1


于是：

    x = 2 + 6 = 8


新模数：

    lcm(6,9)=18


所以合并成：

    x ≡ 8 (mod 18)


================================================
十五、无解例子
================================================

    x ≡ 1 (mod 4)

    x ≡ 2 (mod 6)


差：

    c = 2-1 = 1


而：

    gcd(4,6)=2


但是：

    2 ∤ 1


所以：

    无解


================================================
十六、周期同步题怎么转
================================================

例如：

事件 A：

    每 6 天一次
    第 2 天发生


就是：

    x ≡ 2 (mod 6)


事件 B：

    每 9 天一次
    第 8 天发生


就是：

    x ≡ 8 (mod 9)


问：

    最早什么时候同时发生


就是：

    exCRT


求最小非负解 x。


================================================
十七、如果题目要求“大于某个 L 的最小解”
================================================

exCRT 求出：

    x ≡ A (mod M)


所有解：

    x = A + kM


如果要求：

    x >= L


那么：

如果：

    A >= L

答案：

    A


否则：

    k
    =
    ceil((L-A)/M)


代码：

int k =
    (L - A + M - 1) / M;

int ans =
    A + k * M;


================================================
十八、如果要求“正整数最小解”
================================================

如果 exCRT 得到：

    A > 0

答案就是：

    A


如果：

    A = 0


最小非负解是：

    0


但如果题目要求：

    最小正整数解


则答案：

    M


因为所有解：

    x ≡ 0 (mod M)


================================================
十九、CRT 与 exCRT 怎么选
================================================

题目明确：

    所有模数两两互质


可以：

    普通 CRT


题目没有保证：

    两两互质


直接：

    exCRT


实际上比赛中为了少记代码：

    直接保留 exCRT

就够了。


================================================
二十、为什么代码里用了 __int128
================================================

这些乘法：

    m1 * k

    (m1/d) * m2


可能中间超过 long long。


所以代码里：

    乘法中间值用 __int128


但当前板子最后仍然把：

    新模数
    新答案

存回 long long。


也就是说默认题目保证：

    最终 lcm <= 9e18


如果题目连最终答案都可能超过 long long：

    整个答案和模数都要改成 __int128。


================================================
二十一、常见易错点
================================================

1.
方程：

    x ≡ a (mod m)

一定分清：

    a 是余数
    m 是模数


------------------------------------------------

2.
exCRT 无解条件：

    (a2-a1) % gcd(m1,m2) != 0


------------------------------------------------

3.
新模数不是：

    m1 * m2


而是：

    lcm(m1,m2)

即：

    m1 / gcd(m1,m2) * m2


------------------------------------------------

4.
所有答案都应该标准化：

    a %= m

    if (a < 0)
        a += m;


------------------------------------------------

5.
普通 CRT 只在：

    模数两两互质

时直接套公式。


------------------------------------------------

6.
exCRT 中每合并一次：

    当前方程变成：

    x ≡ now_a (mod now_m)


然后继续合并下一个。


================================================
二十二、赛场写题顺序
================================================

看到多个：

    x ≡ ai (mod mi)


先问：

    mi 是否保证两两互质？


如果没有保证：

    直接 exCRT


写：

1.
    exgcd


2.
    merge_equation


3.
    从第一个方程开始


4.
    一个一个合并


5.
    某次：

    (a2-a1) % gcd(m1,m2) != 0

    直接无解


================================================
二十三、最短速记
================================================

普通 CRT：

    模数两两互质


    M = ∏ mi

    Mi = M/mi

    ti = Mi^(-1) mod mi

    x ≡ Σ ai Mi ti (mod M)


================================================

exCRT：

两个方程：

    x ≡ a1 (mod m1)
    x ≡ a2 (mod m2)


令：

    x = a1 + m1 k


得到：

    m1 k ≡ a2-a1 (mod m2)


设：

    d = gcd(m1,m2)


无解：

    (a2-a1) % d != 0


有解：

    k
    ≡
    ((a2-a1)/d)
    ·
    (m1/d)^(-1)
    (mod m2/d)


然后：

    A = a1 + m1 k

    M = lcm(m1,m2)


得到新方程：

    x ≡ A (mod M)


继续合并下一个。


================================================
二十四、一句话理解
================================================

CRT / exCRT 就是在做：

    把很多个“模条件”

        x ≡ ai (mod mi)

    一步一步合并成：

        x ≡ A (mod M)


普通 CRT：

    模数两两互质


exCRT：

    模数随便
    但每次先判断有没有解。
