【卷积板子 / ACM赛场版】

==================================================
一、普通卷积 NTT
==================================================

处理：
c[k] = Σ a[i] * b[j]，其中 i + j = k
等价：
c[k] = Σ a[i] * b[k-i]

模数：
mod = 998244353
原根：
G = 3

#include <bits/stdc++.h>
using namespace std;

#define int long long

const int mod = 998244353;
const int G = 3;

int qmi(int a, int b)
{
    int res = 1;
    while (b)
    {
        if (b & 1)
        {
            res = res * a % mod;
        }
        a = a * a % mod;
        b >>= 1;
    }
    return res;
}

void ntt(vector<int> &a, int op)
{
    int n = a.size();

    for (int i = 1, j = 0; i < n; i++)
    {
        int bit = n >> 1;

        while (j & bit)
        {
            j ^= bit;
            bit >>= 1;
        }

        j ^= bit;

        if (i < j)
        {
            swap(a[i], a[j]);
        }
    }

    for (int len = 2; len <= n; len <<= 1)
    {
        int wn = qmi(G, (mod - 1) / len);

        if (op == -1)
        {
            wn = qmi(wn, mod - 2);
        }

        for (int i = 0; i < n; i += len)
        {
            int w = 1;

            for (int j = 0; j < len / 2; j++)
            {
                int x = a[i + j];
                int y = a[i + j + len / 2] * w % mod;

                a[i + j] = (x + y) % mod;
                a[i + j + len / 2] = (x - y + mod) % mod;

                w = w * wn % mod;
            }
        }
    }

    if (op == -1)
    {
        int inv = qmi(n, mod - 2);

        for (int &x : a)
        {
            x = x * inv % mod;
        }
    }
}

vector<int> conv(vector<int> a, vector<int> b)
{
    if (a.empty() || b.empty())
    {
        return {};
    }

    int siz = a.size() + b.size() - 1;
    int n = 1;

    while (n < siz)
    {
        n <<= 1;
    }

    a.resize(n);
    b.resize(n);

    ntt(a, 1);
    ntt(b, 1);

    for (int i = 0; i < n; i++)
    {
        a[i] = a[i] * b[i] % mod;
    }

    ntt(a, -1);

    a.resize(siz);

    return a;
}

调用：
vector<int> c = conv(a, b);

结果：
c[k] = Σ a[i] * b[j]，i+j=k


==================================================
二、差卷积 / 相关
==================================================

形式：
c[k] = Σ a[i] * b[i-k]
或
i - j = k

处理：
把一个数组 reverse，再做普通卷积。

例如：
reverse(b.begin(), b.end());
vector<int> c = conv(a, b);

注意：
最后答案位置需要根据数组长度换算偏移。


==================================================
三、FWT：XOR / OR / AND 卷积
==================================================

--------------------------------
1. XOR 卷积
--------------------------------

c[k] = Σ a[i] * b[j]
条件：
i ^ j = k

void fwt_xor(vector<int> &a, int op)
{
    int n = a.size();

    for (int len = 1; len < n; len <<= 1)
    {
        for (int i = 0; i < n; i += len << 1)
        {
            for (int j = 0; j < len; j++)
            {
                int x = a[i + j];
                int y = a[i + j + len];

                a[i + j] = (x + y) % mod;
                a[i + j + len] = (x - y + mod) % mod;
            }
        }
    }

    if (op == -1)
    {
        int inv = qmi(n, mod - 2);

        for (int &x : a)
        {
            x = x * inv % mod;
        }
    }
}

调用：
fwt_xor(a, 1);
fwt_xor(b, 1);

for (int i = 0; i < n; i++)
{
    a[i] = a[i] * b[i] % mod;
}

fwt_xor(a, -1);


--------------------------------
2. OR 卷积
--------------------------------

c[k] = Σ a[i] * b[j]
条件：
i | j = k

void fwt_or(vector<int> &a, int op)
{
    int n = a.size();

    for (int len = 1; len < n; len <<= 1)
    {
        for (int i = 0; i < n; i += len << 1)
        {
            for (int j = 0; j < len; j++)
            {
                if (op == 1)
                {
                    a[i + j + len] = (a[i + j + len] + a[i + j]) % mod;
                }
                else
                {
                    a[i + j + len] = (a[i + j + len] - a[i + j] + mod) % mod;
                }
            }
        }
    }
}


--------------------------------
3. AND 卷积
--------------------------------

c[k] = Σ a[i] * b[j]
条件：
i & j = k

void fwt_and(vector<int> &a, int op)
{
    int n = a.size();

    for (int len = 1; len < n; len <<= 1)
    {
        for (int i = 0; i < n; i += len << 1)
        {
            for (int j = 0; j < len; j++)
            {
                if (op == 1)
                {
                    a[i + j] = (a[i + j] + a[i + j + len]) % mod;
                }
                else
                {
                    a[i + j] = (a[i + j] - a[i + j + len] + mod) % mod;
                }
            }
        }
    }
}


OR / AND 调用方式：

fwt_or(a, 1);
fwt_or(b, 1);

for (int i = 0; i < n; i++)
{
    a[i] = a[i] * b[i] % mod;
}

fwt_or(a, -1);

AND 同理。


==================================================
四、范德蒙卷积
==================================================

Σ C(a,i) * C(b,n-i)
=
C(a+b,n)

即：

Σ[i] C(a,i)C(b,n-i) = C(a+b,n)

看到：
C(a,i) * C(b,n-i)

优先想范德蒙，不要直接 NTT。


==================================================
五、二项式卷积
==================================================

形式：

c[n]
=
Σ C(n,i) * a[i] * b[n-i]

因为：

C(n,i)
=
n! / (i!(n-i)!)

所以：

c[n]
=
n! *
Σ
(a[i]/i!)
*
(b[n-i]/(n-i)!)

构造：

A[i] = a[i] * infact[i]
B[i] = b[i] * infact[i]

D = conv(A, B)

最后：

c[n] = fact[n] * D[n]


==================================================
六、狄利克雷卷积
==================================================

形式：

h[n]
=
Σ[d|n]
f[d] * g[n/d]

记号：

h = f * g

典型：

Σ[d|n] φ(d) = n

即：

1 * φ = id

这种不是 NTT。
一般配合：
莫比乌斯反演
因数枚举
倍数枚举


==================================================
七、gcd / lcm 卷积
==================================================

gcd 卷积：

c[k]
=
Σ[gcd(i,j)=k]
a[i]b[j]

lcm 卷积：

c[k]
=
Σ[lcm(i,j)=k]
a[i]b[j]

常用：
莫比乌斯反演
倍数枚举
因数枚举

不是普通 NTT。


==================================================
八、子集卷积
==================================================

形式：

c[S]
=
Σ[T⊆S]
a[T] * b[S\T]

要求：
T 与 S\T 不相交

常用于：
状压DP
子集DP

常见复杂度：
O(n^2 * 2^n)


==================================================
九、Min-Plus / Max-Plus 卷积
==================================================

Min-Plus：

c[k]
=
min(i+j=k)
(a[i] + b[j])

Max-Plus：

c[k]
=
max(i+j=k)
(a[i] + b[j])

不能直接用 NTT。

一般需要：
凸性
Monge
分治优化
SMAWK
其他DP优化


==================================================
十、赛场识别表
==================================================

看到：

Σ a[i]b[k-i]
-> 普通卷积 / NTT

i+j=k
-> 普通卷积 / NTT

i-j=k
-> reverse 一个数组 + NTT

i^j=k
-> FWT XOR

i|j=k
-> FWT OR

i&j=k
-> FWT AND

Σ C(a,i)C(b,n-i)
-> 范德蒙
-> C(a+b,n)

Σ C(n,i)a[i]b[n-i]
-> 拆 fact / infact
-> 普通卷积

ij=n
或
Σ[d|n] f[d]g[n/d]
-> 狄利克雷卷积

gcd(i,j)=k
-> gcd卷积 / 莫反

lcm(i,j)=k
-> lcm卷积 / 莫反

T⊆S
-> 子集卷积

min(i+j=k)(a[i]+b[j])
-> Min-Plus卷积

max(i+j=k)(a[i]+b[j])
-> Max-Plus卷积


==================================================
十一、最重要的判断
==================================================

普通卷积核心：

c[k]
=
Σ a[i] * b[k-i]

也就是：

i + j = k

并且贡献可以拆成：

A(i) * B(j)

如果一个 O(n^2) 式子能变成：

Σ A[i]B[k-i]

优先考虑卷积优化。


==================================================
十二、常见变形
==================================================

1.

Σ i^2 * (k-i)^3

令：

A[i] = i^2
B[j] = j^3

则：

ans[k]
=
Σ A[i]B[k-i]

普通卷积。


2.

Σ a[i] * b[i-k]

属于差：

i-j=k

reverse 一个数组后做卷积。


3.

Σ C(n,i)a[i]b[n-i]

拆：

C(n,i)
=
n!/(i!(n-i)!)

变成普通卷积。


4.

Σ C(a,i)C(b,k-i)

直接：

C(a+b,k)

范德蒙。


==================================================
十三、长度注意
==================================================

普通卷积：

a 长度 = n
b 长度 = m

答案长度：

n + m - 1

NTT 内部长度取：

>= n+m-1

的最小 2 的幂。


FWT：

数组长度必须是 2 的幂。
