目标：
- 会线性筛求 μ(n)
- 看懂并会自己推最常见的莫比乌斯式子
- 遇到 gcd、互质、恰好等于、倍数计数时能现场套
- 公式尽量用数学记号写清楚，不靠大段文字硬解释


====================================================
0. 先认识几个记号
====================================================

1.  d ∣ n
表示：
    d 是 n 的约数
也就是：
    n % d == 0


2.  ∑_{d∣n} f(d)
表示：
    枚举 n 的所有约数 d，然后把 f(d) 加起来


3.  [P]
表示 Iverson 括号：

    [P] = 1，若命题 P 成立
    [P] = 0，若命题 P 不成立

例如：

    [gcd(a,b)=1]

如果 gcd(a,b)=1，则它等于 1；
否则等于 0。


4.  ⌊n/d⌋
在代码中就是：

    n / d

因为整数除法自动向下取整。


====================================================
1. 莫比乌斯函数 μ(n)
====================================================

定义：

            ⎧  1                       n = 1
            │
μ(n) =      ⎨  0                       n 含平方因子
            │
            ⎩  (-1)^k                  n 为 k 个不同质数的乘积


也就是说：

如果

    n = p1 p2 ... pk

并且这些质数互不相同，

则：

    μ(n) = (-1)^k


例：

    μ(1)  =  1
    μ(2)  = -1
    μ(3)  = -1
    μ(4)  =  0
    μ(6)  =  1
    μ(12) =  0
    μ(30) = -1


====================================================
2. 最重要的恒等式
====================================================

必须记住：

            ∑_{d∣n} μ(d)
        =   [n = 1]


展开就是：

    ∑_{d∣1} μ(d) = 1

而当 n > 1 时：

    ∑_{d∣n} μ(d) = 0


这条式子几乎是所有“互质计数”推导的起点。


====================================================
3. 互质的核心转换
====================================================

因为：

    gcd(a,b)=1

等价于：

    [gcd(a,b)=1] = 1


利用上面的恒等式：

    [gcd(a,b)=1]
    =
    ∑_{d∣gcd(a,b)} μ(d)


又因为：

    d ∣ gcd(a,b)

等价于：

    d ∣ a  且  d ∣ b


所以：

    [gcd(a,b)=1]
    =
    ∑_{d∣a, d∣b} μ(d)


这就是最重要的“开门公式”。

4. 线性筛 μ(n)
====================================================

#include <bits/stdc++.h>
using namespace std;

#define int long long

const int MAXN = 1e6 + 5;

vector<int> prime;
vector<int> vis(MAXN);
vector<int> mu(MAXN);

void sieve()
{
    mu[1] = 1;

    for (int i = 2; i < MAXN; i++)
    {
        if (vis[i] == 0)
        {
            prime.push_back(i);
            mu[i] = -1;
        }

        for (int p : prime)
        {
            if (i * p >= MAXN)
            {
                break;
            }

            vis[i * p] = 1;

            if (i % p == 0)
            {
                mu[i * p] = 0;
                break;
            }
            else
            {
                mu[i * p] = -mu[i];
            }
        }
    }
}


记忆：

若 p ∣ i：

    i·p 出现平方质因子
    ⇒ μ(i·p)=0

若 p ∤ i：

    多了一个新的不同质因子
    ⇒ μ(i·p)=-μ(i)

5. 标准莫比乌斯反演
====================================================

如果：

    F(n) = ∑_{d∣n} f(d)

那么：

    f(n) = ∑_{d∣n} μ(d) F(n/d)


也可以写成：

    f(n) = ∑_{d∣n} μ(n/d) F(d)


这两种完全等价。


----------------------------------------------------
倍数形式
----------------------------------------------------

如果：

    F(n) = ∑_{n∣d} f(d)

即：

    F(n) = f(n)+f(2n)+f(3n)+...

那么：

    f(n)
    =
    ∑_{n∣d} μ(d/n) F(d)


数组 gcd 计数中，经常用这一版。

6. 经典题：1≤x≤n，1≤y≤m，求 gcd(x,y)=1
====================================================

目标：

    Ans
    =
    ∑_{x=1}^n ∑_{y=1}^m [gcd(x,y)=1]


代入：

    [gcd(x,y)=1]
    =
    ∑_{d∣gcd(x,y)} μ(d)


所以：

    Ans
    =
    ∑_{x=1}^n
    ∑_{y=1}^m
    ∑_{d∣gcd(x,y)} μ(d)


交换求和顺序：

    Ans
    =
    ∑_{d=1}^{min(n,m)}
    μ(d)
    · #{x : 1≤x≤n, d∣x}
    · #{y : 1≤y≤m, d∣y}


而：

    #{x : 1≤x≤n, d∣x}
    =
    ⌊n/d⌋


于是：

    Ans
    =
    ∑_{d=1}^{min(n,m)}
    μ(d)
    ⌊n/d⌋
    ⌊m/d⌋


代码：

int coprime_pair(int n, int m)
{
    int ans = 0;

    for (int d = 1; d <= min(n, m); d++)
    {
        ans += mu[d] * (n / d) * (m / d);
    }

    return ans;
}

7. gcd(x,y)=k
====================================================

要求：

    gcd(x,y)=k


令：

    x = ka
    y = kb


则：

    gcd(a,b)=1


因此：

    1≤a≤⌊n/k⌋
    1≤b≤⌊m/k⌋


答案：

    Ans
    =
    ∑_{d=1}^{min(⌊n/k⌋,⌊m/k⌋)}
    μ(d)
    ⌊n/(kd)⌋
    ⌊m/(kd)⌋


也就是直接：

    coprime_pair(n / k, m / k)

8. 数组中有多少对 gcd=1
====================================================

数组：

    a1,a2,...,an


定义：

    cnt[v]
    =
    值 v 出现次数


再定义：

    C_d
    =
    数组中能被 d 整除的元素个数


即：

    C_d
    =
    ∑_{d∣v} cnt[v]


代码：

vector<int> multiple(MAXV + 1);

for (int d = 1; d <= MAXV; d++)
{
    for (int v = d; v <= MAXV; v += d)
    {
        multiple[d] += cnt[v];
    }
}


若统计无序对 i<j：

    两个数都被 d 整除的数对数为

    C(C_d,2)
    =
    C_d(C_d-1)/2


所以：

    Ans
    =
    ∑_{d=1}^{MAXV}
    μ(d)
    · C(C_d,2)


代码：

int ans = 0;

for (int d = 1; d <= MAXV; d++)
{
    int c = multiple[d];

    ans += mu[d] * c * (c - 1) / 2;
}


====================================================
9. gcd 恰好等于 d：为什么要反演
====================================================

定义：

    G(d)
    =
    gcd 恰好等于 d 的数对数量


定义：

    F(d)
    =
    gcd 是 d 的倍数的数对数量


显然：

    F(d)
    =
    ∑_{d∣k} G(k)


因为：

    gcd 是 d 的倍数

就意味着 gcd 可能是：

    d, 2d, 3d, ...


由莫比乌斯反演：

    G(d)
    =
    ∑_{d∣k}
    μ(k/d) F(k)


等价写成：

    G(d)
    =
    ∑_{t≥1}
    μ(t) F(dt)


代码：

for (int d = 1; d <= MAXV; d++)
{
    for (int k = d; k <= MAXV; k += d)
    {
        exact[d] += mu[k / d] * F[k];
    }
}


====================================================
10. gcd 恰好等于 d：更常用的倒序容斥
====================================================

因为：

    F(d)
    =
    G(d)+G(2d)+G(3d)+...


所以：

    G(d)
    =
    F(d)
    -
    ∑_{k≥2} G(kd)


代码：

for (int d = MAXV; d >= 1; d--)
{
    exact[d] = F[d];

    for (int k = d + d; k <= MAXV; k += d)
    {
        exact[d] -= exact[k];
    }
}


这个写法比赛中往往比直接写 μ 更直观。


====================================================
11. 为什么莫比乌斯题总和“倍数”有关
====================================================

“gcd 恰好等于 1”不好直接数。

但是：

    d ∣ gcd(a,b)

很好数。


因为：

    d ∣ gcd(a,b)

⇔

    d ∣ a 且 d ∣ b


所以莫比乌斯反演本质上是在做：

    精确条件
        ↓
    整除条件
        ↓
    倍数计数
        ↓
    再用 μ 做容斥还原

12. 通用套路：求 ∑ f(gcd(x,y))
====================================================

目标：

    Ans
    =
    ∑_{x=1}^n
    ∑_{y=1}^m
    f(gcd(x,y))


若我们能找到 g，使：

    f(n)
    =
    ∑_{d∣n} g(d)


那么：

    f(gcd(x,y))
    =
    ∑_{d∣gcd(x,y)} g(d)


交换求和：

    Ans
    =
    ∑_{d=1}^{min(n,m)}
    g(d)
    ⌊n/d⌋
    ⌊m/d⌋


而由莫比乌斯反演：

    g(n)
    =
    ∑_{d∣n}
    μ(d) f(n/d)


这是一类非常通用的 gcd 求和套路。

13. 经典例子：求所有 gcd 的和
====================================================

目标：

    ∑_{x=1}^n
    ∑_{y=1}^m
    gcd(x,y)


取：

    f(n)=n


而有经典恒等式：

    n
    =
    ∑_{d∣n} φ(d)


因此：

    g(d)=φ(d)


所以：

    ∑ gcd(x,y)
    =
    ∑_{d=1}^{min(n,m)}
    φ(d)
    ⌊n/d⌋
    ⌊m/d⌋


这里不一定需要显式出现 μ，
但思想还是“约数和展开”。

15. 整除分块
====================================================

当 n,m 很大时：

    ∑ μ(d)⌊n/d⌋⌊m/d⌋

不能逐个 d 枚举。


关键：

    ⌊n/d⌋

在一段连续的 d 上值相同。


设当前左端点为 l：

    q1 = ⌊n/l⌋
    q2 = ⌊m/l⌋


则这一段最远可以到：

    r
    =
    min(
        ⌊n/q1⌋,
        ⌊m/q2⌋
    )


所以：

    d ∈ [l,r]

时：

    ⌊n/d⌋ = q1
    ⌊m/d⌋ = q2

16. μ 前缀和 + 整除分块
====================================================

定义：

    M(x)
    =
    ∑_{i=1}^x μ(i)


代码：

vector<int> pre_mu(MAXN);

for (int i = 1; i < MAXN; i++)
{
    pre_mu[i] = pre_mu[i - 1] + mu[i];
}


那么：

    ∑_{d=l}^r μ(d)
    =
    M(r)-M(l-1)


所以：

int coprime_pair(int n, int m)
{
    int ans = 0;

    int limit = min(n, m);

    for (int l = 1, r; l <= limit; l = r + 1)
    {
        int q1 = n / l;
        int q2 = m / l;

        r = min(n / q1, m / q2);

        ans +=
            (pre_mu[r] - pre_mu[l - 1])
            * q1
            * q2;
    }

    return ans;
}

17. 考场推导模板
====================================================

以后遇到“互质 / gcd=1”，直接照着写：

第一步：

    Ans
    =
    ∑ [gcd(...)=1]


第二步：

    [gcd(...)=1]
    =
    ∑_{d∣gcd(...)} μ(d)


第三步：

    d ∣ gcd(...)
    ⇔
    d 同时整除所有变量


第四步：

交换求和：

    先枚举 d


第五步：

统计每个变量中：

    能被 d 整除的数量


如果变量范围是 [1,n]：

    数量 = ⌊n/d⌋


如果变量来自数组：

    数量 = C_d

① gcd(x,y)=1

    ⌊m/d⌋

19. 最容易混淆的两种反演
====================================================

【约数和】

    F(n)
    =
    ∑_{d∣n} f(d)

则：

    f(n)
    =
    ∑_{d∣n}
    μ(d)F(n/d)


----------------------------------------------------

【倍数和】

    F(n)
    =
    ∑_{n∣d} f(d)

则：

    f(n)
    =
    ∑_{n∣d}
    μ(d/n)F(d)


记忆：

约数关系：

    小的 d 往 n 汇总


倍数关系：

    n 往更大的倍数汇总

20. 最短速记
====================================================

核心恒等式：

    ∑_{d∣n} μ(d)
    =
    [n=1]


互质：

    [gcd(a,b)=1]
    =
    ∑_{d∣gcd(a,b)} μ(d)


范围互质对：

    ∑ μ(d)
    ⌊n/d⌋
    ⌊m/d⌋


数组互质对：

    ∑ μ(d) C(C_d,2)


标准反演：

    F(n)=∑_{d∣n}f(d)

    ⇒

    f(n)=∑_{d∣n}μ(d)F(n/d)


gcd=k：

    整体除 k
    转 gcd=1


gcd 恰好为 d：

    “是 d 的倍数”
        ↓
    莫比乌斯反演 / 倒序容斥


大量整除下取整：

    整除分块

21. 一句话理解
====================================================

莫比乌斯反演最常见的作用：

    把

        gcd 恰好满足某条件

    转成

        枚举公共约数 d
        + 统计 d 的倍数

其中最关键的一步永远是：

    [gcd(...)=1]
    =
    ∑_{d∣gcd(...)} μ(d)
