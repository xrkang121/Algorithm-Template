一、基本模型

序列中有：
n 个 +1
n 个 -1

要求：
任意前缀和 >= 0。

方案数是第 n 个卡特兰数。


二、计算公式

Cat(n) = C(2n,n)/(n+1)

也可以写成：

Cat(n) = C(2n,n) - C(2n,n-1)


三、前几项

n：       0  1  2  3   4   5
Cat(n)：  1  1  2  5  14  42


四、常见模型

1. n 个左括号和 n 个右括号组成合法括号序列。

2. n 次入栈和 n 次出栈，任何时候不能空栈出栈。

3. n 个元素按照固定顺序入栈，求合法出栈序列数量。

4. 从 (0,0) 走到 (n,n)，路径不能越过对角线。

5. 满二叉树计数。

6. 凸 (n+2) 边形划分成三角形的方案数。

7. n 个 +1、n 个 -1，任意前缀和 >= 0。


五、递推公式

Cat(0) = 1

Cat(n) = Cat(n-1)
       * (4*n-2)
       / (n+1)
