卷积与 NTT 模板

==================================================
一、可以直接复制的代码
==================================================

功能：
1. 计算两个数组的普通卷积。
2. 数组较短时自动使用暴力卷积。
3. 数组较长时自动使用 NTT。
4. 返回结果已经对 998244353 取模。

使用前注意：
1. 模数必须是 998244353。
2. 如果原代码中已经有 mod、qmi，可以删除重复定义。
3. 输入数组中的值应当已经处于 [0, mod) 中。
4. 这个板子计算的是普通卷积，不是 AND、OR、XOR 卷积。

代码：

const int mod = 998244353;
const int G = 3;

int qmi(int a, int b)
{
    int res = 1;

    while (b > 0)
    {
        if (b & 1)
        {
            res = 1LL * res * a % mod;
        }

        b /= 2;
        a = 1LL * a * a % mod;
    }

    return res;
}

void NTT(vector<int> &a, bool invert)
{
    int n = a.size();

    if (n == 1)
    {
        return;
    }

    // rev只在NTT长度变化时重新计算
    static vector<int> rev;

    // roots只会不断扩展，不会重复计算
    static vector<int> roots{0, 1};

    if ((int)rev.size() != n)
    {
        int k = __builtin_ctz(n);

        rev.assign(n, 0);

        for (int i = 0; i < n; i++)
        {
            rev[i] =
                (rev[i >> 1] >> 1) |
                ((i & 1) << (k - 1));
        }
    }

    // 预处理所有需要使用的单位根
    if ((int)roots.size() < n)
    {
        int k = __builtin_ctz((int)roots.size());

        roots.resize(n);

        while ((1 << k) < n)
        {
            int e = qmi(G, (mod - 1) >> (k + 1));

            for (int i = 1 << (k - 1); i < (1 << k); i++)
            {
                roots[i << 1] = roots[i];
                roots[i << 1 | 1] = 1LL * roots[i] * e % mod;
            }

            k++;
        }
    }

    // 位逆序置换
    for (int i = 0; i < n; i++)
    {
        if (i < rev[i])
        {
            swap(a[i], a[rev[i]]);
        }
    }

    // 蝴蝶操作
    for (int len = 1; len < n; len <<= 1)
    {
        for (int i = 0; i < n; i += len << 1)
        {
            for (int j = 0; j < len; j++)
            {
                int x = a[i + j];
                int y = 1LL * a[i + j + len] * roots[len + j] % mod;

                a[i + j] = x + y;

                if (a[i + j] >= mod)
                {
                    a[i + j] -= mod;
                }

                a[i + j + len] = x - y;

                if (a[i + j + len] < 0)
                {
                    a[i + j + len] += mod;
                }
            }
        }
    }

    if (invert)
    {
        reverse(a.begin() + 1, a.end());

        int inv_n = qmi(n, mod - 2);

        for (int &x : a)
        {
            x = 1LL * x * inv_n % mod;
        }
    }
}

/*
使用方法：
vector<int> C = multiply(A, B);

返回：
C[k] = sum(A[i] * B[j])，其中 i + j = k。

结果长度：
C.size() = A.size() + B.size() - 1。

时间复杂度：
短数组使用 O(nm) 暴力卷积。
长数组使用 O(len log len) NTT。
*/
vector<int> multiply(vector<int> A, vector<int> B)
{
    if (A.empty() || B.empty())
    {
        return {};
    }

    int n = A.size();
    int m = B.size();
    int need = n + m - 1;

    // 数组较短时，直接暴力卷积更快
    if (min(n, m) <= 60)
    {
        vector<int> C(need, 0);

        for (int i = 0; i < n; i++)
        {
            for (int j = 0; j < m; j++)
            {
                C[i + j] += 1LL * A[i] * B[j] % mod;

                if (C[i + j] >= mod)
                {
                    C[i + j] -= mod;
                }
            }
        }

        return C;
    }

    int len = 1;

    while (len < need)
    {
        len <<= 1;
    }

    A.resize(len);
    B.resize(len);

    NTT(A, false);
    NTT(B, false);

    for (int i = 0; i < len; i++)
    {
        A[i] = 1LL * A[i] * B[i] % mod;
    }

    NTT(A, true);

    A.resize(need);

    return A;
}


==================================================
二、最简单的使用示例
==================================================

vector<int> A = {1, 2, 3};
vector<int> B = {4, 5};

vector<int> C = multiply(A, B);

for (int x : C)
{
    cout << x << " ";
}

输出：

4 13 22 15

计算过程：

C[0] = A[0] * B[0]
     = 1 * 4
     = 4

C[1] = A[0] * B[1] + A[1] * B[0]
     = 1 * 5 + 2 * 4
     = 13

C[2] = A[1] * B[1] + A[2] * B[0]
     = 2 * 5 + 3 * 4
     = 22

C[3] = A[2] * B[1]
     = 3 * 5
     = 15


==================================================
三、卷积是什么
==================================================

给定两个数组 A、B，它们的普通卷积 C 定义为：

C[k] = sum(A[i] * B[j])，其中 i + j = k。

等价写法：

C[k] = sum(A[i] * B[k - i])。

暴力计算时最核心的写法：

for (int i = 0; i < A.size(); i++)
{
    for (int j = 0; j < B.size(); j++)
    {
        C[i + j] += A[i] * B[j];
    }
}

所以看到下面这种式子：

F[k] = sum(A[i] * B[k - i])

或者：

F[i + j] += A[i] * B[j]

就应该想到普通卷积。


==================================================
四、卷积为什么等于多项式乘法
==================================================

把数组 A 看成多项式：

A(x) = A[0] + A[1]x + A[2]x^2 + ...

把数组 B 看成多项式：

B(x) = B[0] + B[1]x + B[2]x^2 + ...

两个多项式相乘：

C(x) = A(x) * B(x)

A[i]x^i 与 B[j]x^j 相乘得到：

A[i] * B[j] * x^(i + j)

所以它会给 C[i + j] 产生贡献：

C[i + j] += A[i] * B[j]

因此：

普通卷积 = 多项式乘法。


==================================================
五、NTT 做了什么
==================================================

暴力卷积需要枚举所有 i、j，复杂度为 O(nm)。

NTT 的过程：

1. 把 A、B 从系数表示转换为点值表示。
2. 对应位置直接相乘。
3. 把乘积从点值表示转换回系数表示。

代码流程：

NTT(A, false);
NTT(B, false);

for (int i = 0; i < len; i++)
{
    A[i] = A[i] * B[i] % mod;
}

NTT(A, true);

NTT 不会改变卷积的含义，只是更快地算出完全相同的 C 数组。


==================================================
六、常见应用场景
==================================================

1. 多项式乘法

已知两个多项式的系数，求乘积多项式的所有系数。


2. 统计两数之和

假设 cntA[x] 表示第一组中数字 x 的出现次数，
cntB[y] 表示第二组中数字 y 的出现次数。

令：

C = multiply(cntA, cntB)

那么：

C[s]

表示从第一组选择一个数、从第二组选择一个数，使两数之和为 s 的方案数。

因为每一对 x + y = s 都会贡献：

cntA[x] * cntB[y]


3. 固定总和的方案数

如果题目中出现：

dp[k] = sum(f[i] * g[k - i])

那么整个 dp 数组就是 f、g 的卷积。


4. 组合数学中的阶乘卷积

如果出现组合数：

C(n, k) = n! / (k! * (n - k)!)

常见处理方法是把 n! 提出来，将剩余部分写成：

sum(A[k] * B[n - k])

然后使用卷积。

例如：

sum(f[k] * C(n, k))

= n! * sum((f[k] / k!) * (1 / (n - k)!))

括号中的求和就是卷积。


5. 字符串匹配

把字符是否相同转成 0/1 数组，通过翻转其中一个数组并进行卷积，
可以同时计算字符串在所有对齐位置上的匹配数量。


6. 距离和差值统计

如果需要统计所有数对的和、差或距离，可以将一个频次数组翻转后卷积。

普通卷积天然统计的是下标和；
将一个数组翻转以后，可以把下标差转换成下标和。


==================================================
七、如何快速判断一道题是否使用卷积
==================================================

看到以下结构时优先考虑卷积：

1. C[k] = sum(A[i] * B[k - i])。

2. C[i + j] += A[i] * B[j]。

3. 需要同时统计所有数对的和。

4. DP 转移需要枚举 i + j = k。

5. 组合数拆开阶乘后，出现 k 和 n - k。

6. 多项式相乘。

最核心的判断标准：

两个变量的下标之和固定，并且贡献是两个数组值的乘积。


==================================================
八、注意事项
==================================================

1. 返回数组长度

如果：

A.size() = n
B.size() = m

那么：

C.size() = n + m - 1


2. NTT 长度

NTT 内部长度必须是二次幂，并且至少为：

n + m - 1

板子会自动补到足够大的二次幂。


3. 模数限制

这个板子使用：

mod = 998244353

原根为：

G = 3

因为：

998244353 = 119 * 2^23 + 1

所以支持的 NTT 长度最大为 2^23。

如果题目要求其它模数，不能直接使用这份单模 NTT 板子。


4. 负数处理

放入数组前应当保证：

0 <= A[i], B[i] < mod

如果原数可能为负数，可以写成：

x = (x % mod + mod) % mod;


5. 普通卷积与其它卷积不同

普通卷积：

C[k] = sum(A[i] * B[j])，其中 i + j = k。

AND、OR、XOR 卷积的下标关系不同，需要使用 FWT，不是这份 NTT 板子。
